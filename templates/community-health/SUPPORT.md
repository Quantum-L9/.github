# Support

## Getting Help

### Primary: GitHub Issues

Open a GitHub Issue in the relevant repository using the appropriate template:

| Issue Type           | Template |
| -------------------- | -------- |
| Bug report           | Numbered chooser `1-bug.yml` |
| Feature request      | Numbered chooser `2-feature.yml` |
| Governance violation | [Gov Violation](./.github/ISSUE_TEMPLATE/gov-violation.yml) |
| CI pipeline failure  | [CI Failure](./.github/ISSUE_TEMPLATE/ci-failure.yml) |
| Seed / auto-seed red | [Seed CI Failure](./.github/ISSUE_TEMPLATE/seed-ci-failure.yml) |

Do not clone Cursor-Governance into the consumer workspace root. Law questions:
[CANONICAL_LAW.md](https://github.com/Quantum-L9/Cursor-Governance/blob/main/CANONICAL_LAW.md).
Security: [SECURITY.md](./SECURITY.md) (this repo's advisory form).

### Secondary: GitHub Discussions

For questions, architectural discussions, and community input:
[github.com/Quantum-L9/.github/discussions](https://github.com/Quantum-L9/.github/discussions)

## Out of Scope

The following are **not** supported through Quantum-L9 channels:

- General AI/ML questions unrelated to Quantum-L9 infrastructure
- Debugging third-party tools (GitHub Actions runners, PyPI, npm registry)
- Questions already answered in CANONICAL_LAW.md
- Requests to bypass CI gates or CODEOWNERS requirements

## Response Expectations

| Channel                          | Expected Response Time                                                         |
| -------------------------------- | ------------------------------------------------------------------------------ |
| GitHub Issues (bugs, governance) | 2 business days                                                                |
| GitHub Issues (features)         | 1 week                                                                         |
| GitHub Discussions               | Best effort                                                                    |
| Security vulnerabilities         | See SECURITY.md in this repository                                             |
