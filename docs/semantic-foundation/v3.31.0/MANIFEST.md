## Semantic changes

- `semantics/architecture_patterns.yaml` (`l9.architecture-patterns/global@1`):
  - In `l9.pattern/reference-model-conformance@1`, the edge `conformance_runner compares [reference_model, candidate_implementation]` becomes two edges, `conformance_runner compares reference_model` and `conformance_runner compares candidate_implementation`. Every edge `to` in the ledger is now one node name.
  - In `l9.pattern/authority-candidate-admission@1`, `lifecycle` becomes `{stages: [candidate, admission_evaluated, awaiting_authority, admitted, published]}`. Every pattern `lifecycle` is now an object.
  - Both patterns keep `@1`. Their nodes, relations, states, purpose, preconditions, guarantees, forbidden lists and `compatible_with` lists are unchanged. `l9.pattern/dependency-package@1` is unchanged.
- `docs/adr/README.md`: indexes ADR-028.

No other ledger, rule, profile, criterion, contract or invariant changes.
