# Decisive counterexamples and repairs (design-level)

These are attacks on nearby design choices; no untested draft implementation is claimed.

1. **Incorrect `SV + GT uplift`**: SV already contains a $200 repeated relationship effect; a GT addition of $200 would double count. **Repair:** one canonical revaluation over conditioned trajectories, GT describes responses only.
2. **Unconditional SV merge**: SV source, profile and contract do not exist as admitted `.github` entries at the pinned head. **Repair:** stage GT standalone, isolate GT+SV contract pending independently admitted SV.
3. **One compiled payload = one numerical assessment**: current composition engine only joins selected semantics. **Repair:** distinguish GT-only semantic source composition from consumer-owned numerical assessment, with a reference-only schema.
4. **One value schema with invented missing refs**: an unresolved SV source could not be represented unless a fabricated SV reference were supplied. **Repair:** require SV projection/ref and numerical result only for `evaluated`; `unresolved` can omit them but MUST preserve material Unknowns.
5. **Softmax stationary = Nash**: a player with payoffs (2,0) under temperature 1 has a stationary softmax distribution with a positive unilateral deviation gain >0.2. **Repair:** solution-specific diagnostics, no Nash claim from iteration stability.
6. **GT profile selects shared SV vocabulary**: would duplicate the independent SV profile and risk identity collisions. **Repair:** select only 12 GT terms, one GT invariant and one GT core contract.
7. **New GameTheoryNode**: feasible/probability/payoff responsibilities already have owners. **Repair:** no extra reasoning sibling, provider implementation or new source-class ledger.
8. **Correlated actor responses as independent**: supplier+buyer responses can share market evidence and capacity constraints. **Repair:** joint response dependencies declared or Unknown; no unconditional multiplication.

These repairs are encoded in the final overlays and targeted local synthetic fixtures. They remain candidate requirements, not independently observed deployment behavior.
